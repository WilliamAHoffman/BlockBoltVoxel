# BlockBoltVoxel

Please use 5.4 and the Voxel Plugin Legacy plugin

Uses music and sound effects created by my friend: Vitor Braga

Uses gun models from Kenny.nl

Uses block textures from opengameart.org created by user: aroachifoundonmypillow

Controls:

WASD for moment

Space for jump and double jump

Left Control for sprinting

Left Shift + A/D for strafes

E to craft two guns which are next to eachother

F to pick up a gun

Q to drop a gun

1/2/3/4 for inventory slots

I to toggle headlamp

X to open material selector

Mouse button to fire

R to reload
